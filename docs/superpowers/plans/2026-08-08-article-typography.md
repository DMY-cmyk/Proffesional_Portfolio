# Article Typography ("Hybrid Journal") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the dead `prose` classes on the Research/Notes article pages with a hand-rolled `.article-body` typography layer (serif body, gold-numbered headings, highlighter bold, editorial lists/pull-quotes) and give listing-card summaries the matching serif voice.

**Architecture:** One CSS layer in `src/styles/globals.css` is the single source of truth, driven entirely by existing theme tokens (dark mode is automatic). The two article pages swap their dead class string for `article-body`. Three listing components get a serif class tweak. No new dependencies, no MDX content changes.

**Tech Stack:** Next.js 15 (static export), Tailwind CSS v4 (`@theme` tokens), MDX via next-mdx-remote, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-08-08-article-typography-design.md`

## Global Constraints

- Do NOT install `@tailwindcss/typography` or any other dependency.
- All colors MUST be existing theme tokens (`var(--muted)`, `var(--foreground)`, `var(--accent-highlight)`, `var(--accent-highlight-soft)`, `var(--accent-primary)`, `var(--accent-primary-dark)`, `var(--border)`, `var(--surface-alt)`, `var(--subtle)`). Never hard-code hex values — dark mode depends on this.
- Explicitly excluded by user decision: drop caps, italic lede/first-paragraph treatment, justified text, any animation in article bodies.
- Body font token is `var(--font-display)` ('Newsreader', 'Georgia', serif); label font token is `var(--font-mono)` ('JetBrains Mono', monospace).
- Section numbering must be generated by CSS counters (`decimal-leading-zero`), never hand-written in MDX.
- Existing TOC anchor behavior (`scroll-mt-28` + `headingWithId`) must keep working — style `h2`/`h3`, don't replace them.
- Commit after every task. Run tests with `npm run test:run` (plain `npm run test` starts watch mode and never exits).

import { describe, it, expect } from 'vitest'
import fs from 'node:fs'
import path from 'node:path'

/**
 * Structural guard for the "Hybrid Journal" article typography layer.
 * Asserts the load-bearing rules exist in globals.css so a refactor can't
 * silently drop the reading experience (the way the dead `prose` classes did).
 */

const CSS = fs.readFileSync(
  path.join(process.cwd(), 'src/styles/globals.css'),
  'utf-8'
)

/** Returns the declaration body of the FIRST block matching `selector`. */
function block(selector: string): string {
  const escaped = selector.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
  const match = CSS.match(new RegExp(`${escaped}\\s*\\{([^}]*)\\}`))
  if (!match) throw new Error(`Missing CSS block for "${selector}"`)
  return match[1]
}

describe('.article-body typography layer', () => {
  it('sets a serif reading base with a capped measure', () => {
    const base = block('.article-body')
    expect(base).toContain('font-family: var(--font-display)')
    expect(base).toContain('line-height: 1.85')
    expect(base).toContain('max-width: 65ch')
    expect(base).toContain('counter-reset: article-section')
    expect(base).toContain('overflow-wrap: break-word')
  })

  it('numbers h2 sections with gold mono counters', () => {
    expect(block('.article-body h2')).toContain('counter-increment: article-section')
    const numeral = block('.article-body h2::before')
    expect(numeral).toContain('counter(article-section, decimal-leading-zero)')
    expect(numeral).toContain('var(--font-mono)')
    expect(numeral).toContain('var(--accent-highlight)')
  })

  it('draws a gold rule under each h2', () => {
    const rule = block('.article-body h2::after')
    expect(rule).toContain('width: 36px')
    expect(rule).toContain('height: 2px')
    expect(rule).toContain('var(--accent-highlight)')
  })

  it('renders strong as the gold marker highlight', () => {
    const strong = block('.article-body strong')
    expect(strong).toContain('var(--accent-highlight-soft)')
    expect(strong).toContain('var(--foreground)')
    expect(strong).toContain('font-weight: 600')
  })

  it('gives ordered lists gold mono numerals', () => {
    expect(block('.article-body ol')).toContain('counter-reset: article-item')
    const marker = block('.article-body ol > li::before')
    expect(marker).toContain('counter(article-item, decimal-leading-zero)')
    expect(marker).toContain('var(--accent-highlight)')
  })

  it('styles blockquotes as gold-ruled italic pull-quotes', () => {
    const quote = block('.article-body blockquote')
    expect(quote).toContain('border-left: 2px solid var(--accent-highlight)')
    expect(quote).toContain('font-style: italic')
  })

  it('styles links with the site accent', () => {
    expect(block('.article-body a')).toContain('var(--accent-primary)')
    expect(block('.article-body a:hover')).toContain('var(--accent-primary-dark)')
  })

  it('contains no hard-coded hex colors (dark mode rides the tokens)', () => {
    const layerStart = CSS.indexOf('Article typography')
    expect(layerStart).toBeGreaterThan(-1)
    const layer = CSS.slice(layerStart, CSS.indexOf('view-transition', layerStart))
    expect(layer).not.toMatch(/#[0-9a-fA-F]{3,8}\b/)
  })
})
```

/* ============================================================
   Article typography — "Hybrid Journal" reading experience.
   One reusable layer: add .article-body to any long-form wrapper.
   Every color is a theme token, so dark mode needs no extra rules.
   Spec: docs/superpowers/specs/2026-08-08-article-typography-design.md
   ============================================================ */
.article-body {
  font-family: var(--font-display);
  font-size: 1.0625rem;
  line-height: 1.85;
  color: var(--muted);
  max-width: 65ch;
  overflow-wrap: break-word;
  counter-reset: article-section;
}

.article-body p {
  margin: 0 0 1em;
}

/* Numbered section headings — counter renders 01, 02, … automatically */
.article-body h2 {
  counter-increment: article-section;
  font-size: 1.375rem;
  font-weight: 500;
  letter-spacing: -0.01em;
  line-height: 1.3;
  color: var(--foreground);
  margin: 2.25em 0 0;
}
.article-body h2::before {
  content: counter(article-section, decimal-leading-zero);
  font-family: var(--font-mono);
  font-size: 0.75rem;
  letter-spacing: 0.05em;
  color: var(--accent-highlight);
  margin-right: 0.75rem;
}
.article-body h2::after {
  content: '';
  display: block;
  width: 36px;
  height: 2px;
  background: var(--accent-highlight);
  margin: 0.6rem 0 1rem;
}

.article-body h3 {
  font-size: 1.125rem;
  font-weight: 500;
  letter-spacing: -0.01em;
  color: var(--foreground);
  margin: 1.75em 0 0.5em;
}

/* Bold → gold marker highlight (design decision: replaces plain bold) */
.article-body strong {
  background: var(--accent-highlight-soft);
  color: var(--foreground);
  font-weight: 600;
  padding: 1px 5px;
  border-radius: 2px;
  -webkit-box-decoration-break: clone;
  box-decoration-break: clone;
}

.article-body a {
  color: var(--accent-primary);
  text-decoration: underline;
  text-underline-offset: 3px;
  text-decoration-thickness: 1px;
  transition: color 150ms ease;
}
.article-body a:hover {
  color: var(--accent-primary-dark);
}

/* Editorial lists — gold mono numerals / gold dashes, hanging in the gutter */
.article-body ol {
  counter-reset: article-item;
  list-style: none;
  margin: 0 0 1.25em;
  padding: 0;
}
.article-body ol > li {
  counter-increment: article-item;
  position: relative;
  padding-left: 2.25rem;
  margin-bottom: 0.5em;
}
.article-body ol > li::before {
  content: counter(article-item, decimal-leading-zero);
  position: absolute;
  left: 0;
  top: 0.3em;
  font-family: var(--font-mono);
  font-size: 0.75rem;
  color: var(--accent-highlight);
}

.article-body ul {
  list-style: none;
  margin: 0 0 1.25em;
  padding: 0;
}
.article-body ul > li {
  position: relative;
  padding-left: 1.5rem;
  margin-bottom: 0.5em;
}
.article-body ul > li::before {
  content: '—';
  position: absolute;
  left: 0;
  color: var(--accent-highlight);
}

/* Pull-quote blockquotes */
.article-body blockquote {
  border-left: 2px solid var(--accent-highlight);
  padding: 0.25em 0 0.25em 1.125rem;
  margin: 1.5em 0;
  font-size: 1.0625em;
  font-style: italic;
  color: var(--foreground);
}
.article-body blockquote p {
  margin: 0;
}

/* Elements not in current content, styled so future MDX never renders broken */
.article-body hr {
  border: 0;
  border-top: 1px solid var(--border);
  margin: 2.5em 0;
}
.article-body code {
  font-family: var(--font-mono);
  font-size: 0.85em;
  background: var(--surface-alt);
  border: 1px solid var(--border);
  border-radius: 2px;
  padding: 0.1em 0.35em;
}
.article-body img {
  max-width: 100%;
  border-radius: 2px;
}
.article-body table {
  width: 100%;
  border-collapse: collapse;
  margin: 1.5em 0;
  font-size: 0.9375rem;
}
.article-body th {
  font-family: var(--font-mono);
  font-size: 0.6875rem;
  text-transform: uppercase;
  letter-spacing: 0.1em;
  text-align: left;
  color: var(--subtle);
  border-bottom: 1px solid var(--border);
  padding: 0.5em 0.75em;
}
.article-body td {
  border-bottom: 1px solid var(--border);
  padding: 0.5em 0.75em;
}
```
